# End-to-End-Reporting-Automation
Automated reporting workflow using Python to extract files from Outlook, organize and rename data, update source files, refresh Excel queries, and automate dashboard updates.


Dependencies

The project uses the following Python libraries:

win32com – For automating Microsoft Outlook and Excel operations.

openpyxl – For reading, writing, and managing Excel workbooks.

pandas – For data manipulation, processing, and transformation.
